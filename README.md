Universal Shift Register (4-Bit):

Learned how to design a 4-bit Universal Shift Register using Verilog HDL.
Understood the four operating modes: Hold, Shift Right, Shift Left, and Parallel Load.
Learned how to use a 2-bit selection input (sel) to control different operations.
Understood synchronous operations using a clock signal and active-low reset.
Learned how to write Verilog testbenches and verify different register operations through simulation waveforms.

Johnson Ring Counter:

Learned how to design a Johnson Ring Counter using Verilog HDL.
Understood the concept of inverted feedback, where the complemented output of the last flip-flop is connected to the first flip-flop.
Learned how to generate sequential bit patterns using flip-flops.
Understood the clock-based state transitions and reset operation.
Learned how a 4-bit Johnson counter produces 8 unique states.

By implementing these projects in Vivado, you learn:
1. Creating RTL projects and writing Verilog modules.
2. Developing testbenches for functional verification.
3. Running behavioral simulation and analyzing waveforms.
4. Performing RTL synthesis and understanding the generated hardware structure.
5. Running implementation and understanding FPGA resource utilization.
